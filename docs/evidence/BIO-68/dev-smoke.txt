|---|---|---|---|

GoTrue reports a deleted user as 403 `user_not_found`. `classifyGetUserStatus` maps 403 to `invalid`, so a retry after a lost response returns 401 notSignedIn instead of ok:true. (The function calls /user with the service-role key as apikey and this test used the anon key. GoTrue's user_not_found path is the same either way, but that's inferred, not observed.)
