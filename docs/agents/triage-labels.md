# Triage Labels

| Canonical role    | Local status      | Meaning                                           |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer evaluation is required                 |
| `needs-info`      | `needs-info`      | More information is required                      |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an agent             |
| `ready-for-human` | `ready-for-human` | Requires human implementation or a human decision |
| `wontfix`         | `wontfix`         | Will not be actioned                              |

Record the local status as a `Status:` line near the top of each ticket.
