# Triage Labels

| GitHub label      | Meaning                                           |
| ----------------- | ------------------------------------------------- |
| `needs-triage`    | Maintainer evaluation is required                 |
| `needs-info`      | More information is required                      |
| `ready-for-agent` | Fully specified and safe for an agent             |
| `ready-for-human` | Requires human implementation or a human decision |
| `wontfix`         | Will not be actioned                              |

Apply exactly one of these labels to each open planning or implementation Issue.
