Privacy and validation

Nothing gathered before consent

The form is validated first. Device information is collected only after the learner accepts the notice.

  • Phone make and model
  • Operating system (name + version)
  • OS build ID (firmware-ish)
  • App version
  • Device type (phone / tablet / web)
  • App context (selected language, screen name, UTC timestamp)

Clear form requirements

  • Name cannot be empty or whitespace.
  • Email is required and must use a basic valid format.
  • Description cannot be empty or whitespace.
  • Invalid forms never proceed to consent.

No support server is required

The app opens the learner's existing mail client. It does not contain a GitHub token or automatically send data. The final support inbox will be configured before the feature ships.

What to review

  • Is the support button noticeable without distracting from learning?
  • Does the consent notice explain the collected information clearly?
  • Does the email handoff feel acceptable compared with an in-app send?
  • Does the two-PR sequence make the change easy to review?
